1. Download melon loader (https://github.com/LavaGang/MelonLoader/releases/download/v0.7.3/MelonLoader.x64.zip)

2. Extract melon loader into root folder of harvest skies (where the .exe is)

3. Run the game once without installing harvestskiesunclocker.dll. This generates needed assemblies and folders

4. Exit game and install HarvestSkiesUnlocker.dll into the Mods folder within the root folder of the game

5. Run the game again and enjoy!

***Note:
If using the generate missions option and playing multiplayer, all players must have the mod installed. It will most likely cause some crazy desync if not
If you are just using the money and xp feature, you do not need both players to have it installed, just the one who started the server
